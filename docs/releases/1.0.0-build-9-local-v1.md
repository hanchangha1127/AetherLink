## Rollback Posture

No production rollback package is claimed. Android channel rollback must use a
compatible semantically older build with a higher `versionCode`; ordinary
downgrade installation is not a supported recovery path. A future macOS
rollback should use the current or immediately previous signed DMG only after
compatibility and migration checks, not this local ad-hoc archive.
